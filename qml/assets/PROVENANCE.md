# Original CodePet ginger-cat artwork

All `ginger-*.svg` and `prop-*.svg` assets and `generate_sprites.py` were created originally for CodePet on 2026-10-15. They are distributed under the repository's MIT license, reproduced in `LICENSE` here. Copyright (c) 2026 Greyforge Labs.

The artwork is hand-authored vector geometry generated by the included readable Python source. No third-party imagery, sprites, fonts, sounds, reference sheets, downloaded art, or image-generation service output is incorporated. No Omagotchi/OmaPets asset or external catalog item is vendored; upstream asset rights have not been inferred from a repository license.

Eight poses each have four deterministic, transparent 128 × 128 SVG frames. The frame sequence is idle, walk, sleep, play, food, water, wash, and bathroom. Regenerate with `python3 qml/assets/generate_sprites.py` from the repository root. Output is deterministic. The QML renderer selects a frame supplied by its parent; it owns no animation timer. Sleep is intentionally still; its duplicate frames avoid unnecessary motion during rest. Walk uses alternating paws, while care poses use head, tongue, bubble, or blinking variations.

Four matching transparent props (`prop-food.svg`, `prop-water.svg`, `prop-tree.svg`, `prop-bed.svg`) are generated by the same source and use the same license.

The SVG files use only paths, ellipses, groups, titles, and inline colors. There are no scripts, network URLs, external references, embedded raster data, font dependencies, animation tags, or SVG filters. Their only namespace URL identifies the SVG format and is not fetched.
